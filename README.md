## Overview

Multiplier is built for creators, marketers, and teams who want to reshape one source asset into several publishable formats without manually rewriting the same message over and over. The focus is on taking long-form material and compressing it into concise, channel-specific copy that fits common social and newsletter publishing workflows.

It runs in the browser and uses the Anthropic API for generation. The project also includes Gumroad-based license key unlocking, which can be used as part of the access flow for deployments that are configured for it.

---

## What it does

- Reworks long-form content into platform-specific social copy
- Creates X/Twitter threads from a single source
- Writes LinkedIn posts suited to professional audiences
- Produces Instagram captions with a distinct tone and structure
- Drafts newsletter blurbs for email distribution
- Relies on the Anthropic API for AI-powered generation
- Supports license key unlocking through Gumroad
- Designed for web deployment with Vercel

2. Choose the destination format you want to generate.
3. Review the output for X/Twitter, LinkedIn, Instagram, or newsletter use.
4. Copy the generated text into your publishing workflow.

## Configuration

Multiplier is generally set up through environment variables and application settings used by the web deployment.

Example:
`ANTHROPIC_API_KEY=your_key_here`

If license unlocking is enabled, store the Gumroad-related key or access values in the location expected by your deployment. For local development, keep configuration in the project environment file or hosting dashboard rather than hardcoding secrets in the app.
